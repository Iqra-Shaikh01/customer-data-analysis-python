# Customer Data Analysis Using Python

## Project Overview
This project analyses customer purchasing data to understand customer behaviour, sales trends, membership categories and city-wise performance.

## Tools Used
Python, Pandas, Matplotlib and Seaborn.

## Analysis Performed
Analysed customer age, membership types, purchase amounts and city-wise sales. Created five visualisations to understand customer patterns and business performance.

## Key Findings
Total Customers: 15

Total Sales: ₹40,400

Average Purchase: ₹2,693.33

Top Performing City: Mumbai

Highest Revenue Membership: Silver

## Conclusion
The analysis helped identify customer purchasing patterns and useful business insights through data visualisation.
